How to use

Save a note by typing it into the browser's address bar. Everything is stored in this browser only (localStorage) — nothing is sent anywhere.

1. Add a note from the URL bar

Add ?q= (or ?text=) followed by your note:

Tip: set this page as a custom search engine in your browser (use %s where the note goes) and a note is just a keyword + text away.

2. Special characters in the URL

new line%0A
# (for tags)%23  — a raw # starts the URL fragment and is lost
&%26
+%2B  — a raw + becomes a space

Some sites block bookmarklets with strict security policies.

4. In the app

  • Click a note to edit it — it saves automatically. Esc or click away to finish.
  • Pin 📌 keeps important notes on top. ↑ ↓ reorder (not available while searching/filtering).
  • Tags: write #idea anywhere in a note; click a tag to filter. Links become clickable.
  • Search: every word you type must appear in the note.
  • Delete moves a note to the Trash (Undo appears right away). Trash is emptied after 30 days.

5. Backup & import

  • JSON keeps everything (pins, order, dates, trash). Use it for backups and moving between browsers or devices.
  • TXT and CSV are export-only, for reading or opening in a spreadsheet.
  • Import merges: notes you already have are skipped, nothing is overwritten.

6. Link with the Make Highlights & Notes userscript

With the Tampermonkey script (v2.4 or newer) installed in this browser, this page links up automatically — you'll see 🔗 Userscript linked at the top.

  • Send to this site: on any page press Alt+Shift+N (or use the script's Send to site button / Tampermonkey menu). The selected quote, your note, the page link and a tag for the site's domain are queued, and arrive here the next time this page is open (instantly if it's open already).
  • Highlights tab: a read-only, searchable view of everything you highlighted with the script, grouped by page. Open page jumps to the highlighted text when the browser supports it. Edit highlights on the page itself.
  • The script's All notes panel shows a copy of these notes, refreshed whenever this page is open.
  • The JSON export also includes your highlights (when linked), so the script's own Import can read the same file.
