How to use

Save a note by typing it into the browser's address bar. Everything is stored in this browser only (localStorage) — nothing is sent anywhere.

4. In the app

  • Tabs: All mixes your notes and highlights by time (pinned notes stay on top), Notes, Highlights and Trash. The tab you were on is remembered.
  • Click a note to edit it — it saves automatically. Esc or click away to finish.
  • Pin 📌 keeps important notes on top. ↑ ↓ reorder (only with "Manual order" and no search/filter active).
  • Tags: write #idea anywhere in a note; click a tag to filter. Links become clickable.
  • Checklists: start lines with - [ ] and tick them right on the note. The card shows how many are done.
  • Delete 🗑️ moves a note to the Trash (Undo appears right away). Trash is emptied after 30 days.

5. Search tricks

Every word you type must appear. Extras:

tag:ideanotes with #idea
is:pinned  is:note  is:highlightonly that kind
is:todo  is:openhas a checklist / has unticked items
has:linkcontains a link
from:youtubementions or comes from that site
after:2026-11-01  before:todayby date added (today, yesterday or YYYY-MM-DD)
"exact phrase"quotes keep words together

6. Backup & import

  • JSON keeps everything (pins, order, dates, trash). Use it for backups and moving between browsers or devices.
  • TXT and CSV are export-only, for reading or opening in a spreadsheet.
  • Import merges: notes you already have are skipped, nothing is overwritten.
  • Auto-backup (Chrome / Edge): pick a file once and the site rewrites it whenever your notes change. After restarting the browser, click 💾 Resume backup once to allow it again. If this browser ever has no notes but the file does, it offers to restore instead of overwriting the file.

7. Link with the Make Highlights & Notes userscript

With the Tampermonkey script (v2.5 or newer) installed in this browser, this page links up automatically — you'll see 🔗 Userscript linked at the top.

  • Send to this site: on any page press Alt+Shift+N (or use the script's Send to site button / Tampermonkey menu). The selected quote, your note, the page link and a tag for the site's domain are queued, and arrive here the next time this page is open (instantly if it's open already). On YouTube the link opens the video at the moment you sent it.
  • Highlights tab: a read-only, searchable view of everything you highlighted with the script, grouped by page. Open page jumps to the highlighted text when the browser supports it. Edit highlights on the page itself.
  • The script's All notes panel can show these notes too (Highlights / Site notes / Both), refreshed whenever this page is open.
  • The JSON export also includes your highlights (when linked), so the script's own Import can read the same file.
